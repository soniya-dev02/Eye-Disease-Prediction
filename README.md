## Eye Disease Prediction using Deep Learning

A deep learning-based project that uses a Convolutional Neural Network (CNN) to classify retinal eye diseases from medical images.

### Project Overview

This project applies deep learning techniques to classify eye disease images. Image preprocessing is performed using OpenCV, and a CNN-based model is used for classification.

### Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
- Matplotlib

### Features

- Retinal image preprocessing
- CNN-based image classification
- Eye disease prediction
- Image-based deep learning model

### Deep Learning

The project uses a Convolutional Neural Network (CNN) for image classification.

The workflow includes:

- Image loading
- Image preprocessing
- Data preparation
- CNN model training
- Model evaluation
- Eye disease prediction
